# LinguaVerse Design Plan（frontend-design skill 产物）

> 本文件按 frontend-design skill 流程产出：先定独特视觉方向（概念、色板、字体、布局、动效、原则），再逐条对照 skill 列举的五类"AI 默认套路"自审修订，经用户确认后才进入编码。

## 1. 设计概念：语言护照（The Linguistic Passport）

**一句话**：学一门语言，就是去往一个新的国度。每节课是旅途一站，每个词是一枚印章，每完成一级，护照上多一枚签证。

**主题来源**：护照内页、邮戳、签证贴纸、邮票齿孔、老式旅行地图、集邮册、墨水批注、三种文字系统（拉丁字母 / 平假名片假名 / 韩文音节）。

**为什么是它**：语言学习产品常见视觉是卡通绿（多邻国）或通用 SaaS 卡片。本概念把"分级路径、连续学习、成就徽章、多语种"这些业务结构**直接变成视觉语言**——课程地图是路线，完成是盖章，级别是签证，社区是旅人明信片。有叙事、有触感、与竞品拉开差异。

**那个记忆点（boldness 只花一处）**：课时结算的**"盖章时刻"**——一枚旋转的邮戳重重落下，油墨在纸面上微微晕开。全站其余部分保持安静、克制。

## 3. Type — 刻意的字体选择

- **Latin 展示字**：Fraunces（可变衬线，使用光学尺寸与 SOFT 轴，书卷气且可变出个性；备选 Instrument Serif 若实施时显得太常见）
- **中文展示字**：Noto Serif SC（思源宋体）——与 Fraunces 共同构成"旅行手账出版物"语气
- **正文**：Inter + Noto Sans SC；行高 1.6；标题行高 1.2
- **外文语料**：Noto Sans JP / Noto Sans KR / Inter，保证假名片假名与韩文音节字形
- 类型阶梯：Display 52 / H1 32 / H2 24 / H3 19 / Body 16 / Caption 13；标题 letter-spacing -0.01em；宋体正文行高 1.75
- 行宽：正文列 ≤ 38em（约 70 个中文字符以内）
- 禁止：单个词斜体/异色强调、ALL CAPS 标签、无意义 eyebrow、链接尾缀 "→"、中点拼接 meta 串

## 4. Layout — 概念布局与 ASCII

**对齐**：默认左对齐（手账/书页气质）；结算与盖章时刻使用居中；不用两端对齐。

**核心布局语汇**：

1. **护照对页（学习页）**：左页学、右页批注
2. **路线图（课程地图）**：虚线旅程 + 站点印章，不用 01/02/03 数字标签（顺序由路线承载）
3. **邮票齿孔卡（课时/帖子）**：卡片上下边缘用一排小圆孔表达"可撕下收藏"
4. **签证贴纸（级别）**：微旋转 -2deg 的矩形贴纸 + 烫金细线
5. **圆邮戳（完成态/徽章）**：双层圆环 + 日期弧排，盖下时旋转 -8deg

## 5. Motion — 克制

- **唯一编排时刻**：结算页盖章（下落 + -8° 旋转归正 + 油墨晕开 300ms，一次完成）
- 响应式动作：闪卡真实 3D 翻面、路线站点点亮、签证贴纸轻微翘起
- 不做：每个 section 的 fade-slide-up、每张卡 hover 位移、装饰漂浮
- `prefers-reduced-motion` 时盖章改为瞬时呈现

## 6. 文案原则

- 用户视角："管理提醒"而非"webhook 配置"；动词即结果（按钮"发布帖子"，提示"已发布"）
- 空状态是邀请："还没有到期的词，去学一节新课吧"；错误不道歉、说清怎么修
- 语种标签用母语自称：English / 日本語 / 한국어

| skill 点名的默认套路 | 本案是否落入 | 说明与修订 |
|---|---|---|
| ① 奶油底 #F4F1EA + 高反差衬线 + 陶土 #D97757 | 有风险，已修订 | 初稿纸色偏奶油 → 改为**冷调亚麻 #EFEDE4**，并以大面积深墨蓝 #1B2A3D 形成"护照封皮 vs 内页"对比；强调色用**邮戳朱红 #C2452F 而非陶土橙**；衬线仅承担标题/语料，不做高反差杂志排版 |
| ② 近黑底 + 酸性绿/朱红荧光 | 否 | 深色是蓝墨（非近黑），朱红是低饱和印泥色（非荧光），且只在盖章/CTA 小面积出现 |
| ③ 报纸式细线、零圆角、密栏 | 部分借鉴，已区隔 | 细线保留但仅作纸线；圆角只出现在**邮票/签证/邮戳有语义处**，不是全站统一 radius |
| ④ SaaS 等距圆角卡 + 同一种灰影 + 渐变装饰 | 否 | 卡片语言为齿孔邮票/签证贴纸；投影为"纸张叠放"极淡投影（0 1px 2px rgba(27,42,61,.08)）；渐变只用于护照封面一处，不当装饰 |
| ⑤ 模板 chrome（ALL-CAPS eyebrow、中点 meta、"WORD — 片段"、"→"链接） | 否 | 明令禁用；顺序信息由路线图承载，不用 01/02/03 标签；小标签用宋体小字 + 0.08em 字距 |

## 8. 质量地板（不张扬但必须做到）

移动端 390 起响应式、可见键盘焦点、reduced-motion 支持、对比度达标、多语种字体加载、错误/空/加载三态。

## 9. 原型形态与交付

- 原型直接建在 `client/`（React + Vite + Tailwind v4 + Router），**mock 数据层驱动**，所有页面可点击导航；后续接入 Spring Boot 时仅替换数据层，页面与设计系统全部复用。
- 每个页面右上角小标记：MVP（实心邮戳）/ P1（描边戳）/ P2（虚线戳），便于评审识别阶段归属，正式实现时移除。
- P1/P2 页面用真实感样例内容填充（不做 lorem 占位），交互做到可点可切换，数据为本地 mock。
