# LinguaVerse 多语种在线学习平台 - 产品需求文档（MVP）

## Overview

- **Summary**：构建一款支持英语、日语、韩语三种语言学习的在线教育平台（产品名 LinguaVerse，暂定名），采用**前后端分离架构**（React SPA + Spring Boot RESTful API + MySQL），提供分级课程体系、四大互动学习模块（单词记忆、语法练习、口语跟读、听力训练）、学习进度追踪、用户注册登录、个性化学习路径推荐、社区交流与成就激励系统，打造沉浸式语言学习体验。
- **Purpose**：让中文母语用户在一个产品内完成"测水平 → 学课程 → 练技能 → 看进度 → 获激励 → 同好交流"的完整闭环，提升语言学习的持续性与趣味性。
- **Target Users**：
  - 零基础至中高级的英语/日语/韩语中文母语学习者；
  - 有碎片化学习需求、希望获得个性化学习安排的自学用户；
  - 希望通过社区互动与成就机制保持学习动力的用户。

## 阶段规划（需求优先级）

> 本次只交付 **MVP** 范围；P1/P2 仅作路线图记录，不进行设计与实现。

### MVP（本次交付）—— 跑通完整学习闭环 + 真实服务端

- 真实注册登录（JWT 鉴权、bcrypt 密码哈希、MySQL 持久化）；
- **注册后入门引导**（选择想学语种 → 定级或直接开始 L1）；
- 三语种六级课程框架（L1–L3 真实语料、L4–L6 即将开放）；
- 入门定级测试、选课、课时顺序解锁；
- 单词/语法/听力/口语四大模块，含课时结算与 XP；
- **每日学习目标（10/30/60/100 XP 四档）与今日学习时长统计**；
- 进度仪表盘、规则驱动的"今日学习计划"；
- 社区最小集合：语种筛选信息流 + 发帖 + 评论 + 点赞 + 删除自己的内容；
- 8 枚可真实触发的成就徽章 + XP 等级；
- 游客品牌落地页；
- 桌面/平板/手机三端响应式与沉浸式视觉。

> MVP 详细需求见下文 Functional Requirements（FR-1 ~ FR-18）。

### P1（下一阶段，不实现）—— 社交深化、账户完善、运营能力

正式条目见文末「需求池（P1/P2）」章节，概要：账户增强（头像上传/改密/注销/重置）、独立生词本与多档 SRS、学习提醒与消息中心、社区增强（盖楼/详情页/主页/关注/私信/举报审核）、XP 周排行榜、补签卡与更多徽章、L4 课程、管理后台、课程搜索与收藏。

### P2（中长期，不实现）

L5–L6 全量课程与更多语种、真人音频库、AI 对话与精准发音评测、会员支付与学习证书、班级教务 B 端、PWA/移动 App/邮件推送、数据导出。正式条目同样见「需求池（P1/P2）」。

## Goals

- 一次注册即可学习三种语言，学习数据在服务端按账户隔离、统一汇总。
- 课程按能力分级组织，学习路径有先后秩序（解锁机制）与入门定级。
- 四个练习模块覆盖"词汇—语法—听—说"技能面，反馈即时、数据可追踪。
- 进度数据可视化（XP 经验、连续学习天数、各语言/各模块掌握度）。
- 系统基于用户水平与薄弱环节生成"今日学习计划"。
- 社区与成就系统提供社交动力与长期激励。
- 沉浸式、现代化的视觉与交互体验，桌面端与移动端均可使用。

## Non-Goals

- 不实现 P1/P2 所列功能（头像上传、修改密码、生词本、评论盖楼、关注私信、排行榜、管理后台、L4+ 全量内容、更多语种、AI/真人语音、支付、PWA 等）。
- 不提供学习证书导出、班级/教务管理、家长监护等 B 端能力。
- 不做云部署与运维（仅保证本机 localhost 可启动；数据持久化于本机 MySQL，生产化部署在 P1 规划）。
- 不实现英语/日语/韩语之外的语种（但数据结构预留可扩展性）。
- L4–L6 仅展示分级框架并标记"即将开放"，不提供真实课程内容。
- 不引入 UI 自动化测试框架与 CI 流水线（以手动走查 + 构建/类型检查验证）。

## Background & Context

- 当前工作目录为空，属于全新项目；前端环境 Node v24.14.0 + npm 11.9.0 已就绪；本机现有 JDK 8（**实现前需用户自行安装 JDK 17**）、Maven 3.9.11；MySQL 8 需本机安装并创建空库 `linguaverse`（账号密码配置于 `application.yml`）。
- **架构（已确认 Q1=B，后端 Java）**：前后端分离双工程：
  - `client/`：Vite + React 18 + TypeScript（严格模式）+ Tailwind CSS v4 + React Router + Zustand + lucide-react；自绘 SVG/CSS 图表；开发期通过 Vite proxy 把 `/api` 转发到后端 :8080；
  - `server/`：**Java 17 + Spring Boot 3.x + Spring Security + MyBatis-Plus + MySQL 8**；Maven 构建；分层为 controller/service/mapper（entity/dto/vo/config/common）；JWT 用 jjwt、密码用 BCryptPasswordEncoder、入参校验用 Jakarta Validation；数据库连接与 JWT 密钥走 `application.yml` + 环境变量；
  - 前后端 DTO 采用"**契约先行、手工对齐**"：在 `server/` 维护接口契约（REST 路径、请求/响应字段、状态码），前端按同一份契约封装 API 客户端；
  - 启动：后端 `mvn spring-boot:run`（:8080，首次启动自动执行 DDL 建库表并灌入课程/社区种子）；前端 `npm install && npm run dev`（:5173）；
  - REST 风格 JSON API（context-path `/api`）；所有学习业务规则（解锁、SRS、XP、Streak、成就判定、推荐）在服务端 service 层实现，前端只做展示与交互。
- 听力与口语音频不依赖录音素材，使用浏览器 Web Speech API：SpeechSynthesis（en/ja/ko 合成播放，含语速/逐句控制）；口语评分用 SpeechRecognition（Chromium 支持），不支持时降级为三档自评。**（已确认 Q3 接受）**
- 课程内容为人工编排的真实教学语料（词汇、语法讲解、例句、听力逐句文本、跟读句子），非随机生成。**Q2 已确认：本期仅 L1–L3 真实内容。**
- UI 文案语言：简体中文；学习语料分别为英文、日文、韩文并配中文释义。
- **交付路线（三阶段）**：Phase 0 先交付**覆盖 MVP/P1/P2 全部需求对应页面（53 个视图）的可点击前端原型**，视觉遵循 [design-plan.md](./design-plan.md) 的「语言护照」设计系统，mock 数据驱动；Phase 1 实现 Spring Boot 后端并将原型数据层切换为真实 API（MVP 范围）；Phase 2 打磨回归。原型即后续正式前端，页面资产全部复用，不做废弃式原型。

## Functional Requirements（均为 MVP 范围）

### 游客与账户

- **FR-1 注册登录与会话**：未登录访客看到品牌落地页；用户可使用"用户名 + 密码"注册（用户名唯一、密码 ≥ 6 位）；密码在服务端经 BCrypt 加盐哈希后存入 MySQL；登录成功返回 JWT，前端保存于 localStorage 并在后续请求携带；支持退出；刷新页面凭 token 恢复登录态；token 缺失/过期访问受保护 API 返回 401，前端拦截后跳转登录页（登录后回跳原页面）。
- **FR-2 个人资料**：用户可修改昵称、选择预设头像、切换当前主修语言、调整每日学习目标档位；可查看账户统计（加入天数、XP 总量、累计完成课时数、累计学习时长）。头像上传/改密/注销/数据重置不在 MVP。

### 入门引导

- **FR-17 注册后入门引导（Onboarding）**：首次登录的新用户进入三步引导：欢迎页 → 选择首个想学语种（英/日/韩，自动创建 enrollment 并设为主修语言）→ 选择"做定级测试（推荐）"或"从 L1 直接开始"；完成后进入对应定级/课时页面。已完成引导的用户之后登录直接进入学习首页；引导状态服务端记录，跳过引导时默认英语 + L1。

### 分级课程体系

- **FR-3 语种与分级**：平台提供英语、日语、韩语三个语种；每个语种按 6 级框架（L1 入门 / L2 初级 / L3 中级 / L4 中高级 / L5 高级 / L6 精通，对标 CEFR A1–C2）组织课程。
- **FR-4 课程结构**：层级为"语种 → 级别 → 单元 → 课时"；每个课时包含词汇、语法、听力、口语四类学习环节；L1–L3 提供完整真实内容（每语种 3 级 × 2 单元 × 2 课时），L4–L6 仅元数据并标记"即将开放"。
- **FR-5 定级测试**：新用户可对每个语种选做定级测试（若干道词汇/语法客观题），服务端按正确数给出建议起始级别并持久化；可接受建议或自选 L1 开始。
- **FR-6 选课与解锁**：用户可选择语种加入学习（创建 enrollment）；课时全局顺序解锁（完成前一课时才解锁下一课时，跨单元连续）；已完成课时可重复进入；单元/级别进度在课程地图可见。

### 互动学习模块

- **FR-7 单词记忆**：闪卡展示单词（外文、音标/假名注音/韩文罗马音、词性、中文释义、例句+译文、发音按钮）；用户翻转卡片并标记"认识/模糊/不认识"；服务端按 SRS-lite 固定间隔档更新掌握度（认识：掌握+2 档/约 3 天后到期；模糊：+1 档/约 1 天；不认识：重置/当天到期）；词汇掌握度分四档（新词/学习中/熟悉/掌握）；提供到期单词复习队列入口。
- **FR-8 语法练习**：语法点中文讲解 + 外文例句（可发音），随后作答客观题（单选/填空/改错），每题提交即时判对错、显示正确答案与解析；环节结束给出正确率并持久化。
- **FR-9 听力训练**：合成语音播放对话/短文，支持整段播放、逐句重播、正常/慢速（0.7x）切换、原文默认隐藏可手动显示；完成理解题（单选/判断）后判分解析；无可用语音包时播放调用不报错，可正常作答。
- **FR-10 口语跟读**：逐句播放示范音，用户录音跟读；浏览器支持 SpeechRecognition 时按识别文本与目标句归一化相似度给 0–100 分并逐句反馈；不支持时提供"流利/一般/再练练"三档自评映射分值；得分持久化且环节可完成。
- **FR-11 课时结算**：四环节全部完成后服务端事务性结算：写入课时完成记录（幂等，重复完成不重复发奖）、发放 XP、更新 Streak、判定成就；结算页展示本次 XP、单词数、各模块正确率、最佳跟读分，并提供"下一课时"直达。

### 学习进度追踪

- **FR-12 活动数据记录**：服务端记录每次学习活动（课时完成、单词标记、语法/听力/口语成绩、学习日期、本次学习时长秒数），作为仪表盘、推荐与成就的唯一数据源；学习时长由课时会话计时并在结算时上报，按当地日期聚合为"今日/累计学习分钟"。
- **FR-13 进度仪表盘**：展示 XP 与用户等级（含下一级进度）、连续学习天数、今日已学分钟数、各语种课程完成百分比、四模块训练量与平均正确率、词汇掌握分布；以自绘 SVG/CSS 图表呈现；新活动后返回页面数据刷新。

### 每日目标

- **FR-18 每日学习目标**：用户拥有四档可选每日目标（10 / 30 / 60 / 100 XP 每日，默认 30 XP）；学习首页与仪表盘展示"今日目标环"（今日已获 XP / 目标 XP）及达标状态；推荐引擎在当日已达标时把计划文案切换为鼓励式（"今日目标已达成，再学一点可巩固连胜"）；目标在资料页可随时切换，仅影响展示与推荐文案，不影响任何解锁规则。

### 个性化推荐

- **FR-14 今日学习计划**：首页调用服务端规则引擎生成当日计划，输入含：是否已定级、到期复习词数、当前语种未完成课时、各模块历史正确率薄弱项、Streak 状态、每日目标达标状态；至少返回 3 条推荐，每条含类型、理由文案（"因你……建议……"）、数量信息与直达链接；完成对应活动后重新获取即刷新。

### 社区交流

- **FR-15 社区动态（最小集合）**：信息流按时间倒序列示帖子（头像、昵称、语种标签、正文、点赞数、评论数、时间），支持按语种筛选；登录用户可发帖（标题 ≤ 128 字、正文必填且 ≤ 2000 字，选语种标签）、点赞/取消赞、发表评论（≤ 1000 字）、删除自己发布的帖子（删除后其评论与点赞一并移除）与自己的评论；预置种子帖子与评论；数据存服务端。评论盖楼/关注/私信/举报/编辑内容不在 MVP。

### 成就激励

- **FR-16 成就与 XP**：内置 8 枚徽章——初学乍练（完成第一节课）、三日不辍（连续学习 3 天）、一周坚持（连续学习 7 天）、十课达人（累计完成 10 节课）、词汇新星（累计掌握 50 个单词）、满分通关（单节课正确率达到 100%）、三语行者（加入 3 个语种的学习）、社区新星（在社区发布第一条帖子）；XP 由学习活动获取并按阈值映射等级；徽章在达成时由前端轮询/结算响应带出并弹层庆祝，成就墙展示已得（含日期）/未得（含条件与进度）。

## Non-Functional Requirements

- **NFR-1 可运行性**：具备 JDK 17、Maven、MySQL 8 的本机上：创建空库后在 `server/` 执行 `mvn spring-boot:run`（:8080，自动建表与种子），在 `client/` 执行 `npm install && npm run dev`（:5173）即可使用；`mvn package`（后端编译打包）与 `npm run build`（前端打包）均零错误；浏览器核心流程控制台无 error。
- **NFR-2 响应式**：390px / 768px / 1440px 三宽度下全部页面可用，无横向溢出、文字重叠或控件不可点。
- **NFR-3 沉浸式设计**：统一的主题色/渐变视觉语言、卡片化布局、翻转/奖励/过渡微动效；学习页专注无干扰；游客落地页具备产品感染力。
- **NFR-4 服务端持久化与隔离**：全部业务数据存于 MySQL 8（InnoDB）；重启后端进程、重启浏览器后数据不丢失；多账户数据通过 JWT 鉴权与 SQL 查询条件（user_id）严格隔离。
- **NFR-5 性能**：本机环境下前端首屏可交互 ≤ 3 秒；常规 API 响应 ≤ 300ms（本地 MySQL、单用户数据量）；列表查询为高频路径建必要索引；学习动画在 390px 宽度下流畅。
- **NFR-6 可访问性基线**：主要交互可键盘操作、焦点可见，图标按钮有 aria-label，表单关联 label，heading 语义结构完整。
- **NFR-7 浏览器兼容**：Chromium（Chrome/Edge）为验收浏览器；Web Speech API 不可用时听力/口语功能优雅降级且不崩溃。
- **NFR-8 代码质量**：前端 TypeScript 严格模式、后端 Java 17 + Maven 编译零警告级错误；后端严格按 controller/service/mapper 分层、业务规则集中在 service；前端 UI 与 API 数据层解耦；SQL 全部经 MyBatis `#{}` 参数化，禁止字符串拼接。
- **NFR-9 安全基线**：密码 BCrypt 哈希（不落明文）；Spring Security 过滤链 + JWT 认证，除注册/登录/健康检查外 API 均需认证；Jakarta Validation（@Valid + 注解）校验请求体；全局异常处理统一错误响应（不向前端泄漏堆栈/SQL）；SQL 注入与越权访问（修改/读取他人数据）被阻断并可通过用例验证。
- **NFR-10 API 可验证性**：核心端点（auth/courses/learn/community）可用 HTTP 请求直接验证，返回结构化 JSON；提供环境重置方式（专用重置 SQL 或重建空库后重启自动灌种）。
- **NFR-11 异常与状态体验**：所有异步操作具备加载中、空数据、失败重试三类状态；网络中断或服务端 5xx 时显示友好提示而非白屏；表单按注解规则即时校验；服务端返回统一错误结构（code/message），前端按 401/403/422 等区别处理。
- **NFR-12 防滥用与答案保护**：注册/登录接口做基础限流（如拦截器内每 IP 每分钟次数上限）防暴力破解；练习题/定级题/听力题的正确答案与解析**不随课程内容接口下发**，仅在用户提交作答后由判题接口返回；社区列表等会增长的接口预留 page/pageSize 分页参数（MVP 单页可全量，但契约先行）。

## Constraints

- **Technical**：
  - 前端使用本机 Node v24 / npm 与公开 npm 包；后端要求 **JDK 17**（本机现为 JDK 8，需用户先行升级）、Maven 3.9（已具备）、**MySQL 8**（本机安装，创建空库 `linguaverse`，utf8mb4 字符集）；
  - 不引入 Redis/MQ 等额外中间件（限流以单机拦截器实现；缓存、消息等列入 P1/P2）；
  - 浏览器语音能力受 Web Speech API 与操作系统语音包限制；
  - 后端仅监听本机 localhost:8080，不配置 HTTPS 与域名（生产部署见 FR-P1-11）。
- **Business**：
  - MVP 课程语料规模以"足够演示完整学习闭环"为准：三语种 × L1–L3 × 2 单元 × 2 课时，每课时 6–10 词、1–2 语法点、1 段听力、3–6 句跟读。
- **Dependencies**：
  - 前端：React 18、Vite、TypeScript、Tailwind CSS v4、Zustand、React Router、lucide-react；
  - 后端：spring-boot-starter-web / security / validation、MyBatis-Plus、mysql-connector-j、jjwt、Lombok（可选）、Maven；
  - 课程内容以 `server/src/main/resources/content/*.json` 维护，启动时由种子器导入。

## Assumptions

- 交付形态已确认为**前后端分离全栈应用：React + Spring Boot 3（Java 17）+ MySQL 8 + JWT**（Q1=B），用于产品演示与功能验证，不做云部署；用户负责在实现开始前安装 JDK 17 与 MySQL 8 并创建空库。
- 界面语言简体中文、学习材料面向中文母语者（Q4 未提异议，按默认执行）；品牌暂定名 LinguaVerse（Q5 未提异议，可随时替换）。
- 验收浏览器为 Chromium（Edge/Chrome）；后端 :8080、前端 :5173 均在本机 localhost。
- 学习内容由开发方人工编排，规模见 Business 约束。

## Acceptance Criteria

### AC-1：注册、登录、鉴权与会话保护
- **Type**: `rule`
- **Given**：访客打开平台
- **When**：用未占用用户名注册 → 自动登录进入应用；退出后以错误密码登录；再以正确密码登录并刷新页面；不携带 token 直接请求受保护 API
- **Then**：注册成功；错误密码被拒并提示；正确密码登录成功；刷新后仍登录；未登录访问受保护页面跳转登录页（登录后回跳）；未授权 API 返回 401
- **Pass Condition**：以上行为全部可观测成立
- **Evidence**：浏览器走查 + Network 面板状态码 + 数据库 users 表中仅见 bcrypt 哈希（无明文密码）

### AC-2：多用户服务端数据隔离
- **Type**: `rule`
- **Given**：A、B 两个注册账户
- **When**：A 完成若干学习并发帖后退出，B 登录查看
- **Then**：B 看不到 A 的学习进度与统计；社区帖子作者归属正确；用 A 的 token 无法操作 B 的数据
- **Pass Condition**：账户间数据零串扰
- **Evidence**：双账户浏览器走查 + 数据库表 user_id 关联抽查

### AC-3：三语种六级课程框架与真实内容
- **Type**: `rule`
- **Given**：已登录用户打开课程中心
- **When**：分别查看英语、日语、韩语
- **Then**：每语种展示 L1–L6；L1–L3 可展开"单元→课时"，课时含词汇/语法/听力/口语四类环节真实语料；L4–L6 可见但标记即将开放且不可进入
- **Pass Condition**：三语种结构一致、内容字段完整无空占位；课程数据由 API 下发而非写死在前端
- **Evidence**：课程页走查 + `/api/courses` 响应 + 种子数据校验

### AC-4：定级测试与建议级别
- **Type**: `rule`
- **Given**：未定级用户
- **When**：完成某语种定级测试并提交
- **Then**：得到与正确数对应的建议级别（全对→较高级别、全错→L1），结果持久化于服务端，可从建议级别开始
- **Pass Condition**：极端得分给出不同且方向合理的建议
- **Evidence**：两次走查 + 刷新后定级仍在 + DB 记录

### AC-5：课时顺序解锁
- **Type**: `rule`
- **Given**：某语种新学员
- **When**：观察未完成第 1 课时时第 2 课时状态；完成第 1 课时后再观察
- **Then**：第 2 课时锁定不可进入；完成后解锁，解锁状态刷新/重登后保持
- **Pass Condition**：锁定与解锁均成立且锁定项无法进入学习页
- **Evidence**：课程地图走查 + DB lesson_completions 记录

### AC-6：单词闪卡与服务端 SRS 复习机制
- **Type**: `rule`
- **Given**：进入课时词汇环节
- **When**：翻转卡片、发音；分别标记认识/模糊/不认识；构造到期时间后打开复习队列
- **Then**：翻转与发音可用；三类标记产生不同掌握档位与到期时间（模糊/不认识更短）；到期词进入复习队列；状态存服务端，刷新保持
- **Pass Condition**：交互、档位、到期排序均可验证
- **Evidence**：学习页走查 + API 请求/响应 + DB word_mastery 表

### AC-7：语法练习即时判分与解析
- **Type**: `rule`
- **Given**：进入语法环节
- **When**：作答单选/填空题逐题提交
- **Then**：即时显示对错、正确答案与解析；环节结束显示正确率；成绩入库并反映到仪表盘
- **Pass Condition**：反馈正确、成绩可持久化查询
- **Evidence**：练习页走查 + DB activities 记录

### AC-8：听力播放控制与理解测验
- **Type**: `rule`
- **Given**：进入听力环节（Chromium）
- **When**：整段播放、逐句重播、正常/慢速切换、原文显隐切换，并完成理解题提交
- **Then**：听到对应语种合成语音（无语音包时调用静默失败但不报错）；语速切换生效；题目判分解析并入库
- **Pass Condition**：控件行为完整、答题可提交判分、控制台无 error
- **Evidence**：浏览器走查 + 控制台检查 + DB 成绩记录

### AC-9：口语跟读评分与降级
- **Type**: `rule`
- **Given**：进入口语环节
- **When**：播放示范句并提交跟读（支持识别时取 0–100 分；不支持时走三档自评）
- **Then**：支持时给出分数与逐句反馈；不支持时显示自评项；任一通路均可标记环节完成且成绩入库
- **Pass Condition**：两条路径至少一条完整走通
- **Evidence**：浏览器走查 + DB 成绩记录

### AC-10：课时结算、解锁与进度落库
- **Type**: `rule`
- **Given**：学员学完一个课时四环节
- **When**：进入结算页
- **Then**：展示 XP、单词数、各模块正确率；课时标记完成、下一课时解锁；仪表盘数值增加；重复完成同一课时不重复发放奖励
- **Pass Condition**：结算数值与实际作答一致、持久化、幂等
- **Evidence**：结算前后走查 + DB lesson_completions/activities 核对

### AC-11：进度仪表盘数据准确
- **Type**: `rule`
- **Given**：有学习记录的账户
- **When**：打开仪表盘，完成一次新活动后返回
- **Then**：至少呈现 XP/等级、Streak、今日学习分钟、各语种完成百分比、四模块统计、词汇分布 6 类指标；数值与服务端活动记录一致且学习后更新
- **Pass Condition**：6 类指标可见且学习前后发生正确变化（完成课时后今日分钟数增加）
- **Evidence**：前后截图 + 接口数据核对

### AC-12：个性化今日计划随状态变化
- **Type**: `rule`
- **Given**：同一账户两种状态（新用户 vs 有到期词与语法低正确率的用户）
- **When**：查看首页今日计划
- **Then**：新用户推荐定级测试/L1 课时；老用户出现到期复习/续学课时/薄弱模块训练；≥ 3 条且每条含理由与直达链接；完成被推荐项后计划刷新
- **Pass Condition**：两种状态推荐明显不同且与数据对应
- **Evidence**：两种状态走查 + `/api/recommendations` 响应

### AC-13：社区发帖、筛选、评论与点赞
- **Type**: `rule`
- **Given**：登录用户
- **When**：发布带语种标签帖子、按标签筛选、评论、点赞/取消赞，随后刷新
- **Then**：新帖出现在信息流顶部且归属正确；筛选生效；评论可见；点赞数增减正确；全部持久化
- **Pass Condition**：四类交互全部生效
- **Evidence**：社区页走查 + DB posts/comments/likes 表

### AC-14：成就徽章触发与成就墙
- **Type**: `rule`
- **Given**：新账户
- **When**：在会话中依次完成首课时、累计掌握 50 词、任一练习满分、发布首帖
- **Then**：达成瞬间弹出徽章庆祝；成就墙对应徽章变为已获得并显示日期，未得徽章显示条件与进度；XP 与等级联动增长
- **Pass Condition**：至少 4 枚徽章真实触发、状态准确
- **Evidence**：触发走查 + 成就墙截图 + DB achievement_unlocks

### AC-15：服务端持久化、重启可用与生产构建
- **Type**: `rule`
- **Given**：运行中的全栈工程
- **When**：执行 `npm run build`（前端）与 `mvn package`（后端）；完成核心流程后重启 Spring Boot 进程并刷新浏览器
- **Then**：前端 vite 打包与后端 Maven 编译打包零错误；重启后账户、进度、社区数据完整保留
- **Pass Condition**：两项构建退出码 0 且重启后数据不丢
- **Evidence**：构建输出 + 重启走查

### AC-16：多端响应式可用性
- **Type**: `rule`
- **Given**：应用运行中
- **When**：在 390px、768px、1440px 浏览落地页、首页、课程地图、学习页、社区、成就墙
- **Then**：无横向滚动、无重叠遮挡，导航与主要操作可完成
- **Pass Condition**：三宽度 × 六页面无阻断性布局问题
- **Evidence**：浏览器截图矩阵

### AC-17：注册后入门引导
- **Type**: `rule`
- **Given**：刚注册完成的新用户
- **When**：首次登录进入应用；完成"选语种 → 定级/直接开始"引导；退出后重新登录
- **Then**：首次登录被引导至 onboarding；选择语种后自动加入该语种并设为主修；选"定级"进入测试页、选"直接开始"进入 L1 第 1 课时；再次登录不再出现引导直接进首页；引导状态在 DB 中持久化；跳过引导时默认英语 + L1
- **Pass Condition**：三条路径（定级/直接开始/跳过）行为均正确且引导只出现一次
- **Evidence**：浏览器走查 + DB users.onboarded/enrollments 记录

### AC-18：每日学习目标
- **Type**: `rule`
- **Given**：已登录用户
- **When**：查看首页/仪表盘目标环；在资料页切换四档目标；完成学习活动使今日 XP 跨过目标值
- **Then**：默认标准档 30 XP；切换后目标环分母即时变化且持久化；达标后目标环显示完成态、推荐文案变为鼓励式；未达标时显示差额
- **Pass Condition**：档位切换、进度随 XP 增长、达标态与文案变化均成立
- **Evidence**：资料页/首页走查 + 接口响应

### AC-U1：沉浸式视觉与交互品质
- **Type**: `rubric`
- **Dimension**：视觉现代感、品牌一致性、动效与学习氛围
- **Scale**：1-5
- **Anchors**：1 = 通用后台模板观感、无动效；3 = 整洁可用但缺乏品牌感；5 = 多邻国级别沉浸氛围：统一主题色与图标体系、渐变/卡片得当、翻转/奖励/过渡动效自然、落地页有感染力
- **Pass Threshold**：>= 4
- **Evidence**：落地页、首页、课程地图、学习页、结算/徽章弹层截图

### AC-U2：学习内容的教育质量与语料准确性
- **Type**: `rubric`
- **Dimension**：三语种语料真实性、释义准确性、分级匹配度、讲解清晰度
- **Scale**：1-5
- **Anchors**：1 = 机翻感/错误/空缺；3 = 基本正确但分级混乱；5 = 拼写/语法/注音（含假名、韩文音变）准确、释义到位、难度递进、讲解可支撑自学
- **Pass Threshold**：>= 4
- **Evidence**：三语种课时抽样走查

### AC-U3：个性化推荐的相关感
- **Type**: `rubric`
- **Dimension**：推荐与水平/薄弱项/复习需求的匹配度及理由可解释性
- **Scale**：1-5
- **Anchors**：1 = 固定无关；3 = 大体相关但无差别无理由；5 = 覆盖定级/续学/复习/补短/保活五类场景，排序合理、理由让用户认同
- **Pass Threshold**：>= 4
- **Evidence**：多状态账户首页走查
